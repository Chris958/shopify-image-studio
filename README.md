# Shopify Image Studio

用于 Shopify 网站氛围图制作的多品牌工作台：沉淀品牌规范，按模块生成电脑与手机端预览，并使用真实品牌字体叠加活动文案，确认后导出精确尺寸图片。

## 功能

- 独立品牌项目：素材、设计规范版本、任务和历史记录；记住上次选择的真实项目。
- 发布规范后，尚未生图的未绑定任务自动引用；工作台可选择规范版本，历史任务保持原版本，显式切换会创建新任务。
- 上传 Logo、参考图、产品图、字体及品牌资料；人工整理或调用多模态模型提炼规范。
- 首页 Banner、页面 Header、活动模块等尺寸模板，以及项目自定义尺寸。
- 模型档案和任务路由：Responses、Chat Completions、Images 兼容接口，可填写自己的模型 ID。
- API Key 在浏览器中用口令加密保存；服务器仅在当次调用中使用。
- 低清预览、按方案和设备保存全部图片版本、从旧版继续调整、双端分别确认。
- 电脑端和手机端各有调整输入框，可单独提交或一次提交双端；每端支持独立高清增强、PNG/JPG/WebP 和 ZIP 导出。
- 图片可拖动框选最多 8 个区域并填写备注，生成原图坐标对应的透明区域蒙版用于局部编辑。
- 主标题、副标题、短描述、CTA 独立图层，品牌字体锁定、自动换行和位置微调。

## 图片版本与局部调整

在每张图片下方选择历史版本，再填写该端的调整要求或添加框选备注。单端调整只处理该端；一起调整会分别使用两端的指令和区域。新结果保存为新版本，旧图仍可选，历史任务中的旧版图片会自动兼容。框选标记只用于编辑，不会出现在导出图中。

确认任意一端后，可点击该图下方的“高清输出”，无需等待另一端确认。生成高清版本后需要重新确认，再下载对应设备的图片。局部编辑需要模型服务支持 Images 编辑接口和 mask 参数；模型可能对框外画面做少量修改，请检查预览再确认。文字图层仍由画布使用品牌字体渲染，可在排版面板独立调整。

## 产品白底图

在导航中打开“产品白底图”，上传主图及同一产品的细节参考（最多 5 张），或从项目素材选择。此模块独立保存任务，不需要先发布氛围图品牌规范，使用项目已配置的图片生成与编辑模型。

项目可保存一套默认棚拍规范：光线方向、清晰 / 柔和投影、主体占比和补充要求。固定要求为纯白背景、完整主体、原图视角、真实颜色与材质，不添加营销文案。新任务沿用项目规范，图片版本保留当时的规范快照。

流程：生成低清预览 → 调整或框选备注 → 确认版本 → 生成高清版本 → 再次确认 → 下载。历史版本可单独选择继续修改。已有图片的任务锁定原始素材，更换产品请新建任务。PNG、JPG、WebP 最终均为不透明白底 1500 × 1500，完整保留模型图，不裁掉产品；模型原生尺寸依模型而异。检查产品结构、Logo 与材质细节后再确认用于销售页面。

## Shopify 优化导出

白底图确认高清版本后，可在“Shopify 优化导出”中生成网站版。尺寸固定为 1500 × 1500，默认 WebP / 质量 85，可选 JPG，并提供 60–95 质量滑杆及画质优先、均衡、更小体积预设。

预览显示同尺寸 PNG 母版与优化文件的实际字节大小、体积变化及并排对比；可按 100% / 200% 像素放大并同步滚动检查纹理、Logo 和投影。每次压缩均从原始画布编码，不对压缩结果反复压缩。修改格式或质量后，需更新预览并重新确认；确认后记录格式、质量和体积，再提供独立下载链接。压缩只在浏览器进行，不调用图片模型，原始版本和 PNG 母版继续保留。若新格式反而更大，会如实提示。

内部验证可临时将 `tests/shopify-export-review.tsx` 复制为 `app/shopify-export-qa/page.tsx`，修改导入路径为 `../components/`、`../../lib/`，检查编码格式、真实文件大小、对比、旧参数失效及版本切换；发布前删除临时路由。

## 本地开发

需要 Node.js >= 22.13 和 pnpm 11。使用锁文件安装依赖：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

工作台只显示你的真实项目，不包含内置示例项目、示例图片或预填活动文案。创建项目、上传素材并发布品牌规范后，选择规范版本开始创作。模型调用需要自行配置模型服务、模型权限和 API Key；仓库不包含凭证。

```sh
pnpm typecheck
pnpm test
pnpm build
```

应用基于 React 19、Vinext/Vite，服务端运行在 Cloudflare Workers。托管清单位于 `.openai/hosting.json`，`DB` 为 D1、`BUCKET` 为 R2。首次访问时应用创建所需数据表。正式项目接口需要 ChatGPT 身份认证，托管部署需配置相应身份服务及存储绑定；本地模型配置页面不代表正式环境认证已配置。

## 代码结构

- `app/studio.tsx`：品牌项目、规范、工作台、历史与模型配置。
- `app/components/studio-dialog.tsx`：弹窗、焦点约束、背景滚动锁定。
- `app/api/`：项目和文件隔离、模型调用及任务记录。
- `lib/atmos-render.ts`：精确尺寸画布、真实字体、文字布局和 ZIP。
- `lib/atmos-versions.ts`：双端版本迁移、历史选择、分支调整和输出校验。
- `app/components/image-version-controls.tsx`：版本缩略图、框选和区域备注。
- `lib/atmos-vault.ts`：浏览器本机凭证加密。
- `tests/core.mjs`：认证、数据隔离、不可变规范、任务规范关联、项目选择、模型请求及导出测试。

部分内部文件名和浏览器存储键保留 `atmos` 前缀，以兼容已有配置和项目备份。新导出的备份使用 `shopify-image-studio-project-v1`，同时支持导入旧格式。

## 布局回归检查

将 `tests/layout-review.html` 临时复制到 `public/__layout-review.html`，启动预览后访问 `/__layout-review.html`。检查完删除公开目录中的副本，避免发布测试入口。

检查宽度 320、390、550、600、768、900、1100、1280，弹窗额外检查高度 480。覆盖概览、素材、品牌规范、生成、文案排版、历史、模型配置；点击“检查当前布局”核对横向溢出和弹窗边界。弹窗中使用 Tab/Shift+Tab 应保持焦点，Escape 应关闭并恢复入口焦点。

内部图片交互检查可临时将 `tests/image-controls-review.tsx` 复制为 `app/image-controls-qa/page.tsx`，将导入路径调整为 `../components/` 和 `../../lib/`，在 `/image-controls-qa` 验证版本切换、拖动框选、备注、蒙版和单端确认输出。测试不调用模型、不写项目；发布前删除临时路由。

白底图交互检查使用 `tests/product-cover-review.tsx`：临时复制为 `app/product-cover-qa/page.tsx`，导入路径改为 `../components/` 与 `../../lib/`，访问 `/product-cover-qa`。该检查使用内存数据与合成测试图，不调用模型；发布前删除临时路由。覆盖原图选择、生成、历史、框选、确认、高清、精确尺寸下载和失败恢复。

## 数据与部署

代码仓库仅包含源代码，不包含用户项目、上传素材、数据库、浏览器凭证或本机状态。项目备份用于迁移业务数据，代码仓库用于版本管理。连接测试仅验证对应接口响应，真实多模态和生图能力需要实际任务验证。
